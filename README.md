# Wildfire-Safety-Node-and-Autonomous-Gate-Lockdown-System-
An offline, autonomous edge node on Arduino Uno to mitigate wildfire risks when grids fail. It processes local thermal data (DHT22) and wind vectors to self-determine hazards. When safe limits breach, it bypasses internet limits to instantly engage acoustic alerts and activate dual servos to mechanically deploy entry barriers and safety signage.
